## 🤝 Como ser adicionado

Contribuiu com o projeto? Adicione seu nome através de um Pull Request!

1. Fork o repositório
2. Edite este arquivo adicionando suas informações
3. Envie um Pull Request

Aceitamos contribuições de todos os tipos:
- 💻 Código
- 📝 Documentação
- 🎨 Design
- 🐛 Reporte de bugs
- 💡 Ideias e sugestões
- 🎤 Palestras em eventos
